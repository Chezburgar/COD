Briefing

Two five-operator squads, one contested industrial yard. First team to the score limit — or the higher score when the clock expires — takes the match.

Credits

Operator model: Meshy AI rigged character export supplied by the player.
Level design referenced from “FPS low Poly Map” by Asad.habib on Sketchfab — the geometry here is an original rebuild in that layout and style.
Rendering with three.js. Networking over WebRTC via PeerJS.
Every sound in the game is synthesised in the browser at runtime with the Web Audio API — there are no audio files.
